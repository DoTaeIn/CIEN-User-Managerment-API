# CIEN API Document

## 개요

CIEN API는 회원 관리 및 데이터베이스 관리를 효율적으로 수행하기 위해 개발되었습니다. 회장단 및 관리자가 회원 정보를 손쉽게 조회하고 수정할 수 있도록 설계되었습니다.

## 문서 링크

API의 상세한 설명 및 사용 방법은 아래의 Notion 문서에서 확인할 수 있습니다:

[CIEN API Document](https://oil-twine-794.notion.site/CIEN-API-Document-c120478f9982401c9f10621ad006ad3f?pvs=4)

## 주요 기능

- **회원 정보 조회**: 특정 조건을 만족하는 회원 데이터를 검색할 수 있습니다.
- **회원 정보 수정**: 회원의 전화번호, 전공 등 특정 필드를 업데이트할 수 있습니다.
- **회원 추가**: 새로운 회원을 데이터베이스에 등록할 수 있습니다.
- **회원 상태 관리**: 활동 상태(활동, 휴면, 동문, 탈퇴)를 변경할 수 있습니다.

## API 사용 방법

- 데이터베이스 구조 변경 시 API에 미치는 영향을 신중히 검토해야 합니다.
- 회원 관리의 효율성을 위해 데이터 입력 형식을 유지해 주세요.
